# 01 Single Neuron

## About
One artificial neuron with 3 inputs. It finds the weighted sum and passes it through ReLU.

## Formula
z = (x1*w1 + x2*w2 + x3*w3) + bias
output = ReLU(z)

## Files
| File | What it does |
|---|---|
| 01_single_neuron.py | Single neuron using NumPy dot product and ReLU |

## Requirements
- Python 3
- NumPy

## Run
python 01_single_neuron.py
